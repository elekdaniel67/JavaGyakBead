Szoftverleltár REST API

Metódus Útvonal Művelet Hozzáférés
GET /api/szoftverek Szoftverek listázása Nyilvános
GET /api/szoftverek/{id} Egy szoftver lekérése Nyilvános
POST /api/szoftverek Új szoftver felvétele Admin
PUT /api/szoftverek/{id} Szoftver módosítása Admin
DELETE /api/szoftverek/{id} Szoftver törlése Admin

A POST, PUT és DELETE kérésekhez adminfiók és Basic Auth szükséges. A POST és PUT kérés törzse JSON.

{
  "nev": "Próba szoftver",
  "kategoria": "Teszt"
}
